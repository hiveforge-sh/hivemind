<feature>
  <name>Graph Traversal Database Methods</name>
  <files>src/graph/database.ts, tests/unit/graph/database.test.ts</files>
  <behavior>
    queryNeighbors(entityId, options?) returns immediate neighbors:
    - Input: entityId string, optional filters (direction, includeRelationships, excludeRelationships, includeEntityTypes, limit)
    - Output: Array of { neighbor_id, rel_type, direction }
    - Handles: bidirectional by default, respects direction filter, returns empty array if entity has no relationships

    querySubgraph(entityId, depth, options?) returns multi-hop traversal:
    - Input: entityId, depth (1-5), optional filters
    - Output: Array of { entity_id, depth, path }
    - Handles: cycle prevention via path tracking, depth cap at 5, returns shortest path to each node

    queryShortestPath(fromId, toId, options?) returns path between entities:
    - Input: fromId, toId, optional filters (includeRelationships, maxDepth)
    - Output: { found: boolean, path: string[], edges: Array<{from, to, type}> }
    - Handles: no path found returns { found: false, path: [], edges: [] }

    getEdgeBetween(nodeA, nodeB) returns edge info:
    - Input: two node IDs
    - Output: { rel_type } or null if no direct edge
  </behavior>
  <implementation>
    Use SQLite recursive CTEs per research patterns:
    - Cycle prevention: path NOT LIKE '%' || new_id || '%'
    - Depth limiting: WHERE t.depth < maxDepth
    - Direction filtering: conditional JOIN on source_id OR target_id
    - Relationship type filtering: AND r.rel_type IN/NOT IN

    Methods should be synchronous (better-sqlite3 is sync).
    Add row interface types for query results.
  </implementation>
</feature>
