Create `src/mcp/graph-tools.ts` with Zod validation schemas following the timeline-tools.ts pattern:

1. **QueryGraphNeighborsArgsSchema**:
   - entityId: string (required) - "Entity identifier (ID, name, or Type:name format)"
   - direction: enum ['outgoing', 'incoming', 'both'] (optional, default 'both')
   - includeRelationships: array of strings (optional) - relationship types to include
   - excludeRelationships: array of strings (optional) - relationship types to exclude
   - includeEntityTypes: array of strings (optional) - only return neighbors of these types
   - limit: number 1-100 (optional, default 50)

2. **QueryGraphSubgraphArgsSchema**:
   - entityId: string (required)
   - depth: number 1-5 (optional, default 2) - "Number of hops to traverse (max: 5)"
   - direction: same as above
   - includeRelationships: same as above
   - excludeRelationships: same as above
   - includeEntityTypes: same as above
   - includeIntermediateNodes: boolean (optional, default false) - "Include nodes at intermediate depths"
   - limit: number 1-200 (optional, default 100)

3. **QueryGraphPathArgsSchema**:
   - fromEntityId: string (required)
   - toEntityId: string (required)
   - includeRelationships: array of strings (optional)
   - maxDepth: number 1-10 (optional, default 6)

4. **ListRelationshipTypesArgsSchema**:
   - No required parameters (empty object)

Export type aliases for each schema (QueryGraphNeighborsArgs, etc.).
