<objective>
Add two CI quality gates that protect long-term code health:

1. **License compliance** — fail the build on any GPL/AGPL production dependency,
   emit a CSV inventory of all production licenses for audit purposes.
2. **Mutation testing** — run Stryker over 7 core modules (≈843 mutants) with the
   vitest runner; thresholds break at 50%, warn under 60%, target ≥80%; publish the
   HTML mutation report as a CI artifact.
</objective>

<tasks>

<task type="auto">
  <name>Task 1: License compliance CI job</name>
  <files>.github/workflows/test.yml</files>
  <action>
Add a `license-compliance` job that runs `npx license-checker --production
--onlyAllow "MIT;Apache-2.0;ISC;BSD-2-Clause;BSD-3-Clause;0BSD;Unlicense;CC0-1.0"`
and uploads a CSV inventory as an artifact. Job must fail on any disallowed license.
  </action>
  <verify>Run job locally / in CI dry-run — exits 0 against current production deps; flags any GPL/AGPL.</verify>
  <done>License job present in test.yml; passes against current 260 production deps.</done>
</task>

<task type="auto">
  <name>Task 2: Stryker config + Vitest harness</name>
  <files>stryker.config.json, vitest.config.stryker.ts, .gitignore, package.json</files>
  <action>
Add `@stryker-mutator/core` and `@stryker-mutator/vitest-runner` as devDependencies.

  <done>Stryker runs successfully end-to-end against the 7 target modules.</done>
