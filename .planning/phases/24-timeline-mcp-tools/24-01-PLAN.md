<feature>
  <name>Timeline date field discovery and validation schemas</name>
  <files>src/mcp/timeline-tools.ts, src/mcp/timeline-tools.test.ts</files>
  <behavior>
    Date field discovery:
    - discoverTemporalTypes() -> scans active template's entityTypes for fields with type === 'date'
    - Returns Array<{ entityType: string; dateFields: Array<{ name: string; required: boolean; description?: string }> }>
    - Filters out entity types with zero date fields
    - Returns empty array if no active template
    - Example: worldbuilding template event type has start_date, end_date -> included; character type has no date fields -> excluded

    validateDateField(entityType: string, dateField: string) -> boolean:
    - Returns true if the entity type has a field with that name AND type === 'date'
    - Returns false if entity type not found or field not a date type

    Zod validation schemas:
    - QueryTimelineRangeArgsSchema: { startDate: ISO8601 string, endDate: ISO8601 string, dateField: string, entityType?: string, sortOrder?: 'asc'|'desc' (default 'asc'), limit?: number (1-1000, default 100) }
    - QueryTimelineBeforeArgsSchema: { date: ISO8601 string, dateField: string, entityType?: string, sortOrder?: 'asc'|'desc' (default 'desc'), limit?: number }
    - QueryTimelineAfterArgsSchema: { date: ISO8601 string, dateField: string, entityType?: string, sortOrder?: 'asc'|'desc' (default 'asc'), limit?: number }
    - QueryTimelineExactArgsSchema: { date: ISO8601 string, dateField: string, entityType?: string, sortOrder?: 'asc'|'desc' (default 'asc'), limit?: number (1-1000, default 100) }
    - ISO8601 validation: use z.string().regex(/^\d{4}-\d{2}-\d{2}$/) for YYYY-MM-DD only (not datetime with time component — worldbuilding dates are date-only)
    - Invalid dates like "2024-13-45" should be accepted by the regex (SQLite handles comparison correctly for string sorting) — keep validation simple, don't validate calendar correctness

    MCP tool definition generation:
    - generateTimelineTools(temporalTypes) -> returns ToolDefinition[] with three tools
    - Tool descriptions dynamically include available date fields per entity type
    - Tool names: query_timeline_range, query_timeline_before, query_timeline_after, query_timeline_exact
    - Follow existing ToolDefinition interface from tool-generator.ts
  </behavior>
  <implementation>
    1. Import templateRegistry and FieldConfig from templates
    2. Import z from 'zod' and ToolDefinition from tool-generator
    3. Create discoverTemporalTypes() scanning activeTemplate.entityTypes
    4. Create validateDateField() checking entity type's fields
    5. Define three Zod schemas with z.string().regex(/^\d{4}-\d{2}-\d{2}$/) for dates
    6. Create generateTimelineTools() returning ToolDefinition[] following existing patterns
    7. Tests should mock templateRegistry.getActive() to return controlled entity types
  </implementation>
</feature>
