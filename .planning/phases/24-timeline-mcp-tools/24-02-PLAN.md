<feature>
  <name>Timeline database queries with generated columns</name>
  <files>src/graph/database.ts, src/graph/database.test.ts</files>
  <behavior>
    initializeDateColumns(dateFields: string[]):
    - Takes an array of date field names (e.g., ['start_date', 'end_date', 'birth_date'])
    - For each field, adds a VIRTUAL generated column: `json_extract(frontmatter, '$.fieldName')`
    - Creates index on each generated column
    - Uses ALTER TABLE ... ADD COLUMN wrapped in try/catch (SQLite does NOT support IF NOT EXISTS for ADD COLUMN — catch "duplicate column" errors to achieve idempotency)
    - Safe to call multiple times (idempotent)

    queryByDateRange(startDate, endDate, dateField, options?):
    - options: { entityType?: string, sortOrder?: 'asc'|'desc', limit?: number }
    - Returns GraphNode[] filtered by dateField BETWEEN startDate AND endDate
    - If entityType specified, adds AND type = ? filter
    - Orders by dateField in sortOrder direction
    - Applies limit (default 100)
    - Falls back to json_extract if generated column doesn't exist

    queryByDateBefore(date, dateField, options?):
    - Returns entities where dateField < date
    - Same options as range query
    - Default sort: desc (most recent first)

    queryByDateAfter(date, dateField, options?):
    - Returns entities where dateField > date
    - Same options as range query
    - Default sort: asc (earliest first)

    queryByExactDate(date, dateField, options?):
    - Returns entities where dateField = date (exact equality)
    - options: { entityType?: string, sortOrder?: 'asc'|'desc', limit?: number }
    - Default sort: asc
    - Uses json_extract(frontmatter, '$.fieldName') = ? in WHERE clause

    queryByDateOverlap(startDate, endDate, startField, endField, options?):
    - For entities with date ranges (e.g., events with start_date and end_date)
    - Matches if entity's range overlaps query range
    - WHERE startField <= queryEnd AND (endField >= queryStart OR endField IS NULL)
    - Entities with NULL end_date treated as ongoing (match if started before query end)

    Row to GraphNode mapping:
    - Reuse existing rowToGraphNode pattern from getAllNodes/getNodesByType
    - Extract into private helper method if not already extracted
  </behavior>
