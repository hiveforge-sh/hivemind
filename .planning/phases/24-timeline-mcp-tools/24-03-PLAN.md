  <name>Task 1: Add timeline methods to SearchEngine and wire server</name>
  <files>src/search/engine.ts, src/server.ts</files>
  <action>
    **SearchEngine changes (src/search/engine.ts):**
    1. Add `queryTimelineRange(startDate, endDate, dateField, options?)` method that:
       - Calls `this.db.queryByDateRange(startDate, endDate, dateField, options)`
       - For each result node, fetches relationships via `this.db.getRelationships(node.id)`
       - Returns results grouped by entity type, each group sorted by date
       - Includes execution time in metadata
    2. Add `queryTimelineBefore(date, dateField, options?)` wrapping `this.db.queryByDateBefore`
    3. Add `queryTimelineAfter(date, dateField, options?)` wrapping `this.db.queryByDateAfter`
    4. Add `queryTimelineExact(date, dateField, options?)` wrapping `this.db.queryByExactDate`

    **Server changes (src/server.ts):**
    1. Import `generateTimelineTools`, `discoverTemporalTypes`, and the four Zod schemas (Range, Before, After, Exact) from `src/mcp/timeline-tools.ts`
    2. In ListToolsRequestSchema handler, after dynamicTools generation:
       - Call `discoverTemporalTypes()` to get temporal types
       - If temporal types exist, call `generateTimelineTools(temporalTypes)` and spread into tools array
    3. In CallToolRequestSchema handler, add cases before the switch statement (after dynamic query/list tool checks):
       - Check if name starts with `query_timeline_`
       - For `query_timeline_range`: parse args with QueryTimelineRangeArgsSchema, validate dateField with validateDateField if entityType provided, call searchEngine.queryTimelineRange, format response
       - For `query_timeline_before`: parse with QueryTimelineBeforeArgsSchema, call searchEngine.queryTimelineBefore
       - For `query_timeline_after`: parse with QueryTimelineAfterArgsSchema, call searchEngine.queryTimelineAfter
       - For `query_timeline_exact`: parse with QueryTimelineExactArgsSchema, call searchEngine.queryTimelineExact
    4. In server `start()` method, after template initialization:
       - Call `this.database.initializeDateColumns(allDateFields)` where allDateFields is the union of all date field names from discoverTemporalTypes()
    5. Format timeline responses: group results by entity type, show date field value, entity name, type, description, frontmatter fields. Use existing formatEntityWithRelationships or a simpler timeline-specific format.

    **Response format for timeline tools:**
    ```
    # Timeline Results: [dateField] [range description]

    Found N entities across M types.

    ## [EntityType] (count)

    ### [Entity Title]
    - **Date**: [date value]
    - **Type**: [type] | **Status**: [status]
    - **ID**: `[id]`
    [key frontmatter fields]
    [relationships if any]

    ---
    *Query: [dateField] [range] | Sort: [order] | Time: Xms*
    ```
